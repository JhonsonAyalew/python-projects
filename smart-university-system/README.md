# Smart Campus Vision System

## Overview
The Smart Campus Vision System is a computer vision–based monitoring and
automation platform developed as a university project. The system applies
face recognition, object detection, and event detection techniques to
support attendance automation, access monitoring, and campus safety
workflows.

The project demonstrates how AI-powered vision systems can analyze
real-time video streams to identify individuals, detect objects, and
respond to predefined events in a structured and automated manner.

---

## System Capabilities

### 1. Face Recognition & Attendance Automation
- Automated student attendance using facial recognition
- Detection of repeated entry attempts within a defined time window
- Attendance logging and validation
- Audio and system alerts for abnormal attendance behavior

### 2. Identity & Access Classification
- Classification of authorized and unauthorized individuals
- Differentiation between registered students and non-registered persons
- Outdoor detection to identify campus members versus visitors

### 3. Object Detection & Safety Monitoring
- Person detection using YOLOv8
- License plate detection for vehicle monitoring
- Weapon detection for safety awareness and risk identification

### 4. Event & Crowd Detection
- Detection of unusual crowd behavior and forced access attempts
- Automated triggering of event-based responses
- Video recording of abnormal situations for review

### 5. Alerting & Reporting
- Automatic notification to administrative systems
- Video evidence generation for security review
- Real-time response support for campus management

---

## Architecture Overview
The system follows a modular architecture:

- **Video Input Module** – Handles live camera feeds and recorded video
- **Vision Processing Module** – Performs detection and recognition tasks
- **Event Detection Module** – Identifies abnormal activities and patterns
- **Alert & Logging Module** – Sends notifications and stores evidence
- **Data Management Module** – Organizes records and event logs
