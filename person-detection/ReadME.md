# YOLOv8 Person Detection

[![Python](https://img.shields.io/badge/python-3.8%2B-blue)](https://www.python.org/) 
[![Ultralytics YOLO](https://img.shields.io/badge/YOLOv8-Ultralytics-orange)](https://docs.ultralytics.com/)  

A **simple Python project** to detect people in images, videos, or live webcam using **YOLOv8** and **OpenCV**. Fast, lightweight, and easy to use with a pre-trained **COCO model**.

## 🔹 Features

- Detects **persons only** from webcam, images, or video files.  
- Draws **bounding boxes** with confidence scores.  
- Lightweight using **YOLOv8n** for real-time performance.  
- Easy to extend for custom datasets or additional classes.
